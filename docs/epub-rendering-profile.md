# EPUB 阅读呈现配置（v1）

Fbooks 将 EPUB 视为受限的可重排阅读文档，而不是需要完整复现的
浏览器页面。目标是保证本地、跨平台、可预测的阅读体验；不执行 EPUB
中的脚本，也不嵌入 WebView。

本配置定义当前渲染边界，以及后续清洗和缓存应遵守的契约。

当前代码已按章节懒读取 XHTML、包内图片与已链接 CSS，并使用 Flutter
Widget 渲染；它尚未把所有输入物化为独立的“清洗后文档”。因此本配置是
当前行为的边界和下一步清洗器的验收标准，不应误读为已经完整实现了下面
每一条拒绝规则。

## 边界与原则

- 保留原始 EPUB 文件和出版物元数据，二者均不因呈现转换而被改写。
- 只使用 EPUB 包内资源；不请求网络，不执行 JavaScript，也不打开嵌入
  的网页或媒体。
- 阅读偏好（字体大小、行高、边距、浅色/深色/护眼主题）优先于出版物
  CSS 的同类属性。
- 不承诺浏览器、EPUB3 阅读系统或 HTML5 的像素级兼容性。无法可靠支持
  的内容必须显式降级，而不是偶然依赖某个平台的实现。

## 章节处理模型

当前实现以章节为单位工作：打开出版物时，在专属 isolate 中读取导航和
章节引用；进入章节时才读取 XHTML、已链接的包内 CSS、以及该章节引用的
图片。读取完成的章节只缓存在该阅读会话内。

长期采用“懒转换、可丢弃派生缓存”的策略：

1. 导入时只验证格式并保存原始文件，不生成第二份完整电子书。
2. 首次阅读某章节时，将其转换为本配置定义的受限阅读文档。
3. 可在后续加入磁盘缓存，键应至少包含原始资产指纹、spine 项标识和
   `renderingProfileVersion`。缓存是可安全删除的派生数据，不能替代原始
   EPUB，也不能成为唯一可恢复副本。
4. 派生缓存应保存清洗后的章节与资源清单，而不是把图片 Base64 复制进
   每份章节 HTML；资源仍按原始包内路径去重。

这比导入时全书转换更省空间、不会拖慢导入，也比每次重新清洗整本书更
稳定。当前会话内缓存已经存在；磁盘派生缓存仍是后续优化。

## v1 支持范围

| 类别 | 支持与呈现规则 |
| --- | --- |
| 文档结构 | `body` 内的文本、`p`、`div`、`section`、`article`、`h1`–`h6`、`blockquote`、`pre`、`code`、`br`、`hr`。章节标题由应用栏显示，章节内首个标题可作为阅读页标题。 |
| 行内文字 | `em`/`i`、`strong`/`b`、`u`、`s`/`del`、`sub`、`sup`、`span` 和普通文本。 |
| 列表 | `ul`、`ol`、`li`，包括常见列表编号和起始值。 |
| 表格 | `table`、`thead`、`tbody`、`tfoot`、`tr`、`th`、`td`、`col`、`colgroup`；宽表应横向滚动。 |
| 图片 | 仅限包内 `img` 的 PNG、JPEG、GIF、BMP。图片按章节懒读取；缺失或无法解码时显示失败状态。SVG 尚不属于 v1。 |
| 链接 | 仅处理指向同一本书另一个 spine 项的相对链接，并跳转到目标章节。外部链接不会打开；同章节锚点和跨章节锚点尚未支持精确定位。 |
| CSS | 读取 XHTML 内的 `style`、`style` 属性，以及 `link rel=stylesheet` 指向的包内样式表。支持由 Flutter HTML 渲染器可映射的基础文字、颜色、间距、边框、列表、表格和简单布局属性。 |

`html`、`head`、`title`、`meta`、`link` 等只用于解析和提取，不作为可见
阅读内容。未知的纯语义容器可以展开其文本子节点；未知的行为性元素则不
应保留其行为。

## 明确不支持或必须降级的内容

- JavaScript、事件属性、表单、`iframe`、`object`、`embed`、`canvas`、
  音频、视频和远程资源。
- SVG、MathML、交互式媒体、固定版式、EPUB 的脚本化导航和 SMIL 媒体
  覆盖。
- CSS `@import`、`url(...)` 资源、`@font-face`、媒体查询、分页规则、
  多栏、动画、变换、绝对/固定定位、浮动、Flex/Grid 和依赖伪元素生成
  内容的排版。
- 对相对链接中锚点片段的精确跳转；目前只能安全跳转到章节。

对于不支持的标签，清洗器应移除行为和危险属性，并保留可读的文本后代；
对于不支持的 CSS，丢弃该声明而非尝试执行。不能因内容存在上述特性而让
阅读页崩溃。

## 清洗输出契约

后续实现清洗器时，输出必须满足：

1. 仅包含本配置允许的标签和属性。
2. 样式仅保留允许的 CSS 属性和值；相对资源路径先解析为包内资源标识。
3. 内部链接改写为稳定的应用章节目标，而不是文件路径或网页 URL。
4. 输出中不包含脚本、事件处理器、网络 URL 或平台相关状态。
5. 清洗版本变更时递增 `renderingProfileVersion`，使旧派生缓存失效。

## 兼容性推进顺序

下一步先补齐 `@import` 与 CSS `url(...)` 的包内解析。之后再评估运行时
字体注册与 `@font-face`：字体会影响中文、日文及特殊字符的排版和缺字，
但只有在 Flutter 渲染器能够可靠应用时才纳入支持范围。任何新增能力都应
先写入本配置并加入含该特性的 EPUB 回归样本。
